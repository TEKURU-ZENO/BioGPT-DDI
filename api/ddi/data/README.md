# External evidence data (not committed)

Generated files placed here are picked up automatically by `api/ddi/evidence.py`
(or point `DDI_DATA_DIR` elsewhere).

| File | Generated by | Source licence |
|---|---|---|
| `external_ddi.json` | `python -m scripts.import_ddinter <csv files>` | DDInter 2.0: free for academic / non-commercial use. Check the terms before redistributing. |
| `label_evidence.json` | `python -m scripts.fetch_label_evidence` | openFDA / DailyMed SPL: public domain |

Both files are git-ignored so that licensed third-party data is never committed by accident.
